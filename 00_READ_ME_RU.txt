ПРОЧТИ МЕНЯ — один архив на два ноутбука
=========================================

Что внутри: всё, что нужно, чтобы с Windows-машины запустить диагностику
карты на втором ноутбуке по SSH и получить готовый отчёт.

  * второй ноутбук: ssh-сервер УЖЕ ЕСТЬ — этот архив его НЕ устанавливает и
    НЕ настраивает. Есть только проверка «до него можно достучаться»;
  * Windows-машина: распаковать архив и дважды щёлкнуть по pcmcia-kit.pyw.
    Нужен только Python 3 (python.org). Ни PowerShell, ни .cmd не нужны.
    Скрипт сам отправит на ноутбук файлы набора, запустит проверки и
    положит отчёт рядом с собой.

Карта и слот PCMCIA не затрагиваются: на карту ничего не пишется.


ШАГ 1. НА НОУТБУКЕ С КАРТОЙ — УЗНАТЬ АДРЕС И ПРОВЕРИТЬ ВХОД
------------------------------------------------------------
Распакуйте архив и на ноутбуке выполните:

    bash ./CHECK_SSH.sh              # без root, быстрая проверка
    sudo bash ./CHECK_SSH.sh         # подробнее: порт, вход по паролю, файрвол
    sudo bash ./CHECK_SSH.sh 2222    # если sshd на нестандартном порту

Скрипт ничего не меняет — только смотрит: работает ли sshd, на каком порту
слушает, разрешён ли вход по паролю, и печатает АДРЕС ноутбука и готовую
команду для Windows.

Если он пишет, что порт 22 не слушается, а sshd на другом порту — просто
запомните этот порт, он понадобится на шаге 2 (--port).

Строка «passwordauthentication no» или «permitrootlogin no» — значит входить
надо обычным пользователем: на Windows добавьте --user ВАШ_ЛОГИН.
Пароль root, если он не задан: sudo passwd root (только если входить root).


ШАГ 2. НА WINDOWS-МАШИНЕ — РАСПАКОВАТЬ И ЗАПУСТИТЬ
---------------------------------------------------
1) Распакуйте архив, например в D:\pcmcia-flash-kit (целиком, не по файлам).
2) Откройте PowerShell в этой папке (Shift + правая кнопка мыши →
   «Открыть окно PowerShell здесь») и выполните:

    python pcmcia-kit.pyw --text info --host 192.168.0.94

   где адрес — тот, что напечатал CHECK_SSH.sh на шаге 1.

   Полезные варианты:

    python pcmcia-kit.pyw --text read            # снять образ
    python pcmcia-kit.pyw --text info --dry-run  # план без подключения
    python pcmcia-kit.pyw --text info --user alex          # свой пользователь
    python pcmcia-kit.pyw --text info --port 2222          # sshd на другом порту
    python pcmcia-kit.pyw --text info --kit-dir D:\pcmcia-flash-kit

3) ssh один раз спросит пароль. Пароль нигде не сохраняется.
4) В папке появится отчёт: otchet-<адрес>-<дата>.txt. Его и присылайте.

Если PowerShell не даёт запускать скрипты:

    python pcmcia-kit.pyw --text info --host 192.168.0.94

Если файл помечен как скачанный из интернета:

    (не требуется: файлы .py не блокируются так, как .ps1)

ВАЖНО: запускать в обычном окне PowerShell, НЕ в PowerShell ISE — в ISE
ssh не сможет спросить пароль.

На Windows нужны только ssh и scp — оба встроены в Windows 10/11.
Файлы набора уходят на ноутбук по scp, отчёт и образ возвращаются тоже scp.
Если ssh нет, в PowerShell от администратора:

    Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0


ЧТО В ОТЧЁТЕ (на что смотреть)
------------------------------
Раздел «7. ПАСПОРТ КАРТЫ ИЗ ATTRIBUTE MEMORY» — главный, и в конце него
строка «ИТОГ РАЗДЕЛА 7: паспорт прочитан: ДА/НЕТ».

  ДА   — карта жива, паспорт (CIS) читается; дело в окнах ядра.
         Дальше можно снимать образ: python pcmcia-kit.pyw --text read
  НЕТ  — смотрите текст под строкой: «сплошные 0xFF» значит карта не
         отвечает (контакты/посадка), «сплошные 0x00» — тоже не отвечает.
         Это НЕ «стёртая карта»: стирается только common memory, паспорт
         остаётся всегда.


ЧТО ГДЕ ЛЕЖИТ
-------------
    pcmcia-kit.pyw   двойной щелчок: окно пульта (самое простое начало)
    pyproject.toml   пакет: команда pcmcia-kit после pip install .
    src/pcmcia_kit/  сам пульт: меню, команды, графическое окно
    README.md        короткое описание набора и его раскладки
    00_READ_ME_RU.txt     этот файл
    PCMCIA_LINEAR_FLASH_СПРАВОЧНИК.md
                          что за карты бывают, как они устроены, где паспорт,
                          переключатели, микросхемы и типовые отказы
    CHECK_SSH.sh       проверка sshd на ноутбуке (запускать там)
    for-windows\           файлы, которые уходят на ноутбук по SSH:
        remote_collect.py     движок: архив → ssh → запуск → отчёт
        collect_all.sh         полный отчёт о карте (выполняется на ноутбуке)
        pcmcia_direct.py       чтение окон памяти и паспорта карты
        pcmcia_flash.sh        добавляет в отчёт разделы --selftest и --diag
    setup_sshd.sh          НЕ НУЖЕН (sshd у вас уже есть); оставлен на случай,
                           если понадобится другой ноутбук без sshd
    collect_all.sh         то же, что в for-windows\ — чтобы можно было
    pcmcia_direct.py       запустить отчёт прямо на ноутбуке без Windows:
    pcmcia_flash.sh            sudo bash ./collect_all.sh
    pcmcia_gui.py          просмотр снятого образа карты (не обязателен)
    remote_collect.sh      сбор отчёта для Linux/macOS-машины, без Python-пульта
    src/pcmcia_direct/        код работы с картой: мост, CIS, питание, чипы,
                              команды NOR, сценарии, командная строка
    SSH_HOWTO_RU.txt         подробности про SSH-цикл
    WINDOWS_REQUIREMENTS_RU.txt  что установить на Windows (коротко)


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
  «Connection refused / timed out»  — не тот адрес или порт: повторите шаг 1,
                                      проверьте, что машины в одной сети.
  «Permission denied»               — другой пользователь: --user логин;
                                      или у root не задан пароль.
  «Набор не найден»                 — архив распакован не целиком: нужна папка
                                      «for-windows» рядом с pcmcia-kit.pyw.
  Отчёт пустой в разделах 6-7       — на ноутбуке не было root: войдите root
                                      или настройте sudo без пароля.
