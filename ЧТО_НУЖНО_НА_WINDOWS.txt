ЧТО НУЖНО НА WINDOWS-МАШИНЕ, С КОТОРОЙ ЗАПУСКАЕТСЯ СКРИПТ
=========================================================

Короткий ответ: 2 программы (обе уже встроены в Windows 10/11) и 2-3 файла
из набора. Всё остальное скрипт сам отправит на ноутбук.


1. ПРОГРАММЫ
------------
   ssh   — клиент OpenSSH. Есть в Windows 10 (сборка 1803) и Windows 11.
   tar   — C:\Windows\System32\tar.exe, есть там же.

Проверить (в PowerShell):

     ssh -V
     tar --version

Если ssh нет — выполните в PowerShell ОТ АДМИНИСТРАТОРА:

     Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0

Если нет tar (сильно старая сборка Windows) — обновите Windows; без него
скрипт работать не сможет (он упакует набор в архив).

PowerShell 5.1 (встроенный) достаточно, PowerShell 7 не обязателен.
ВАЖНО: запускать в обычном окне PowerShell, НЕ в PowerShell ISE —
в ISE ssh не сможет спросить пароль.


2. ФАЙЛЫ В ОДНОЙ ПАПКЕ (например D:\pcmcia-flash-kit)
------------------------------------------------------
   ОБЯЗАТЕЛЬНО:
     remote_collect.ps1     ← сам скрипт, вы его запускаете
     collect_all.sh         ← что выполнится НА НОУТБУКЕ (отчёт)
     pcmcia_direct.py       ← чтение окон памяти и паспорта карты (--probe/--cis)

   ОЧЕНЬ ЖЕЛАТЕЛЬНО:
     pcmcia_flash.sh        ← добавляет разделы 4 (--selftest) и 5 (--diag)

   НЕОБЯЗАТЕЛЬНО:
     pcmcia_gui.py          ← нужен только чтобы открыть снятый образ без карты
     SSH_РАБОТА.txt         ← памятка

Если забыть обязательный файл — скрипт скажет прямо, чего не хватает, и
ничего не отправит:

     ОШИБКА: в D:\pcmcia-flash-kit нет pcmcia_direct.py.

Если нет pcmcia_flash.sh — он предупредит, что разделы 4-5 будут пропущены,
и продолжит (главный раздел 7 соберётся).

Проверка комплекта без подключения:

     .\remote_collect.ps1 -DryRun

покажет найденные ssh/scp, все три шага (копирование набора, запуск,
забор отчёта) и список файлов, которые уйдут на ноутбук по scp.


3. ЧТО НУЖНО НА НОУТБУКЕ (второй машине)
----------------------------------------
   * работающий ssh-сервер:      sudo apt install openssh-server
                                 sudo systemctl enable --now ssh
   * логин и пароль пользователя (root или обычный — обычному нужен sudo)
   * 32-битная система (i386/i686): набор рассчитан на неё; это будет
     видно в отчёте, строка «архитектура»
   * больше ничего ставить не надо: набор и питон-скрипты копируются на
     ноутбук по scp, во временную папку /tmp/pcmcia-collect

Итого на Windows: ssh + scp + файлы набора рядом со скриптом.
(tar больше не нужен: файлы копируются по scp поштучно.)


4. ЗАПУСК
---------
     cd D:\pcmcia-flash-kit
     .\remote_collect.ps1

Если PowerShell не даёт запускать скрипты («выполнение сценариев отключено»):

     powershell -ExecutionPolicy Bypass -File .\remote_collect.ps1

Если Windows помечает файл как скачанный из интернета:

     Unblock-File .\remote_collect.ps1

Результат: otchet-<адрес>-<дата>.txt в той же папке. Его и присылать.
