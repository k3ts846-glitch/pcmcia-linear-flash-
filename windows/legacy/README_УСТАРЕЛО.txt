ПРЕЖНИЕ СЦЕНАРИИ — НЕ ИСПОЛЬЗУЮТСЯ
===================================

С 2.16.0 рабочий путь один и он целиком на Python:

    python pcmcia-kit.pyw              двойной щелчок -> графический пульт
    python -m pcmcia_kit               текстовое меню и все команды
    pcmcia-kit                         то же после `pip install .`

Ни .cmd, ни .ps1 в рабочем пути нет: набор не зависит от PowerShell и от
политики выполнения сценариев.

Что здесь лежит
---------------
Сценарии PowerShell 2.13-2.15 и диагностический .bat — архив, а не запасной
вариант:

    RUN_CTL.ps1, RUN.ps1, RUN_CTL.cmd, RUN.cmd
        пульт с Windows-машины, 2.13-2.15;

    add_key.ps1, remote_collect.ps1, kit_sync.ps1, kit_state.ps1
        ключ доступа, сбор отчёта по ssh, отправка изменившихся файлов,
        запоминание последнего опроса карты;

    collect_pcmcia_info.bat
        диагностический сценарий: что видно про карту и гнездо.

И один действующий файл:

    pcmcia_direct.py
        это НЕ архив: главный движок набора (команды микросхеме через окно
        моста), лежит здесь с 2.16.0. Его читают пакет, пульт и тесты.

Почему здесь больше нет Python-версии 2.16.0
--------------------------------------------
В 2.16.0 рядом лежали pcmcia_win.py, add_key.py и ПУСК.cmd — «запасной
вариант» на Python, который запускался через .cmd. Все три обращались к
модулю kitlib, которого в наборе никогда не было ни в одной ревизии git,
поэтому не запускались вовсе:

    python windows/legacy/pcmcia_win.py --help
    ModuleNotFoundError: No module named 'kitlib'

В 2.17.19 они убраны: запасной вариант, который падает на первом же импорте,
хуже отсутствия запасного варианта — он отнимает время именно тогда, когда
что-то уже пошло не так. Заменять нечем и не нужно: клиентская часть 2.16.0
и есть пакет src/pcmcia_kit, он работает (`python -m pcmcia_kit`, вход по
ключу — `python -m pcmcia_kit key`).

Как воспользоваться архивом
---------------------------
По прямому назначению — не стоит: пути, по которым эти сценарии вызывались,
изменились. Читать — можно: в них осталась логика опроса карты и разбора
отчётов. Если всё же запускать, то из этой папки (сценарии ищут файлы набора
рядом с собой) и с PowerShell 5.1 или новее.

Проверка
--------
Набор проверяет tests/test_legacy.py: здесь не должно быть .py кроме
pcmcia_direct.py (остальные нечем проверить — пакет из набора их не видит),
список сценариев в этом описании обязан совпадать с тем, что лежит в папке,
рабочий путь должен существовать, а подсказки набора не должны отправлять
пользователя к файлам, которых нет.
