ПРЕЖНИЕ СЦЕНАРИИ — НЕ ИСПОЛЬЗУЮТСЯ
===================================

С 2.16.0 рабочий путь один и он целиком на Python:

    python pcmcia-kit.pyw              двойной щелчок -> графический пульт
    python -m pcmcia_kit               текстовое меню и все команды
    pcmcia-kit                         то же после `pip install .`

Ни .cmd, ни .ps1 в рабочем пути нет: набор не зависит от PowerShell и от
политики выполнения сценариев.

Что здесь лежит
---------------
Две промежуточные версии, оставленные на ОДИН выпуск — на случай, если на
рабочей машине что-то пойдёт не так:

    ПУСК.cmd, pcmcia_win.py, add_key.py
        версия 2.16.0 «на Python, но ещё через .cmd». Заменена пакетом
        src/pcmcia_kit (то же самое, но оформлено как программа: pyproject.toml,
        console-скрипт pcmcia-kit, графический пульт).

    RUN_CTL.ps1, RUN.ps1, RUN_CTL.cmd, RUN.cmd, add_key.ps1,
    remote_collect.ps1, kit_sync.ps1, kit_state.ps1
        версии 2.13-2.15 на PowerShell. Заменены полностью.

Как воспользоваться
-------------------
Скопируйте нужный файл в корень набора рядом с pcmcia_ctl.sh и pcmcia_direct.py
(сценарии PowerShell ищут файлы набора в своей папке) и запустите. Для .cmd и
.ps1 нужен PowerShell 5.1 или новее; для pcmcia_win.py / add_key.py — только
Python 3.9+ и клиент OpenSSH.

Проверяется набором tests/test_legacy.py: он убеждается, что файлы на месте и
не противоречат текущей версии, но рабочим путём их не считает.
