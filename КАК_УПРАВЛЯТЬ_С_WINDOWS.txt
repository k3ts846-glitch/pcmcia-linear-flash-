КАК УПРАВЛЯТЬ КАРТОЙ С WINDOWS-МАШИНЫ
=====================================
Вы сидите за Windows, карта стоит в ноутбуке с Linux (192.168.0.94).
Всё, что нужно, уже в наборе: ssh и scp встроены в Windows 10/11,
на ноутбуке ничего запускать руками не надо.

Нужен только Python 3.9 или новее (python.org, при установке отметьте
"Add python.exe to PATH"). Ни PowerShell, ни командных файлов набору не
требуется: раньше они были, теперь нет.

ГЛАВНОЕ ПРО ЗАПУСК (запомнить один раз)
---------------------------------------
    python pcmcia-kit.pyw              окно пульта            работает сразу
    python pcmcia-kit.pyw --text ...   то же без окна         работает сразу
    python -m pcmcia_kit ...           меню и команды         нужно
                                       py -3 -m pip install .

  Почему так: "python -m pcmcia_kit" ищет пакет там, где Python ставит
  библиотеки. Если набор не устанавливали, запускайте pcmcia-kit.pyw:
  он сам подключает папку src. Или установите пакет одной командой: рядом
  появится команда pcmcia-kit, а файлы набора останутся на месте.

САМОЕ ПРОСТОЕ: двойной щелчок по pcmcia-kit.pyw
------------------------------------------------
    Открывается окно пульта: поля подключения, кнопки действий, журнал.
    Кнопки те же, что пункты меню: паспорт карты, образ, проба записи,
    запись, сверка, стирание, полный отчёт, микросхема, проверка набора.

    Почему .pyw: Windows связывает это расширение с pythonw.exe, поэтому
    окно консоли не открывается. Ошибок в кавычках и кодировке, которыми
    славились .cmd, здесь быть не может: пульт один и он на Python.

ОДИН РАЗ: без пароля (иначе пароль спросится на каждом шаге)
------------------------------------------------------------
    cd C:\pcmcia-ssh-kit
    python pcmcia-kit.pyw --text key --host 192.168.0.94

    (создаст ключ %USERPROFILE%\.ssh\pcmcia_key, положит его на ноутбук,
     проверит вход и напечатает готовую команду запуска; пароль - один раз)

ТЕКСТОВОЕ МЕНЮ И КОМАНДЫ
------------------------
    python pcmcia-kit.pyw --text                меню (пункты 1..13)
    python pcmcia-kit.pyw --text info           паспорт карты и вердикт
    python pcmcia-kit.pyw --text read           снять образ и забрать к себе
    python pcmcia-kit.pyw --text write -i card.bin   отправить и записать
    python pcmcia-kit.pyw --text erase --yes    стереть карту
    python pcmcia-kit.pyw --text verify -i card.bin  сверить файл с картой
    python pcmcia-kit.pyw --text canwrite       можно ли писать эту карту
    python pcmcia-kit.pyw --text diag           окна памяти, драйвер, dmesg
    python pcmcia-kit.pyw --text report         полный отчёт
    python pcmcia-kit.pyw --text chip           что за микросхема (не пишет)
    python pcmcia-kit.pyw --text selftest       проверить набор (карта не нужна)

  После установки (py -3 -m pip install .) то же самое короче:
    pcmcia-kit info      pcmcia-kit read      pcmcia-kit selftest

  К любой команде добавляется:
    --host 192.168.0.94   --user root   --port 22
    --key %USERPROFILE%\.ssh\pcmcia_key
    --yes                 не спрашивать подтверждение
    --dry-run             показать план и ничего не делать
    --kit-dir D:\pcmcia-flash-kit      если запускаете из другой папки

ЧТО ПРОИСХОДИТ ПРИ ЗАПУСКЕ (пять шагов, видно в выводе)
-------------------------------------------------------
    1) папка на ноутбуке      ssh: mkdir -p /tmp/pcmcia-ctl
    2) набор                  scp: только ИЗМЕНИВШИЕСЯ файлы (по md5)
    3) образ (если нужен)     scp: файл + сверка md5 до записи
    4) работа с картой        ssh: pcmcia_ctl.sh ... с показом хода
    5) результат              scp: образ или отчёт обратно к вам

ЧЕГО НЕ БУДЕТ
-------------
  * Ничего не устанавливается на ноутбук: файлы кладутся в /tmp и убираются.
  * Образ в /root не удаляется: его могли не забрать.
  * При отказе входа, недоступном ноутбуке или неверном md5 работа
    останавливается ДО записи на карту, и об этом сказано по-русски.

ЧЕГО ПОКА НЕ ПРОВЕРЕНО (важно перед записью)
--------------------------------------------
  * Чтение, паспорт, определение микросхем и окна памяти проверены на живой
    карте (Centennial FL32M-20-11, 4 МиБ, 2 x Am29F016, 5 В).
  * Стирание и запись на живой карте НЕ ПРОВЕРЕНЫ: они проверены на модели
    микросхем. Поэтому СНАЧАЛА ПРОБА (пункт 9 меню, fwprobe), и только если
    она прошла - запись.
  * Если в паспорте отмечен переключатель защиты от записи, пульт откажется
    писать (код 4). Писать все равно можно только явным --force-write.
  * Если паспорт лежит в первом блоке массива, пульт остановится перед
    стиранием блока 0 (код 5): стирание сотрёт паспорт.
